Firestore Index Banayein

Har query khud chala kar dekhta hai ki uska index hai ya nahi — jo nahi hai, uska "Index banayein" button yahin mil jayega.

Ye page kuch badalta nahi hai. Sirf padh kar batata hai. Index tabhi banega jab aap khud button dabakar Firebase Console me Create index par click karenge.

Ek index banne me ek-do minute lagte hain. Console me "Building" dikhega, phir "Enabled". Tab tak site waise hi chalti rahegi — code bina index ke bhi kaam kar leta hai, bas thoda slow.

Sab index ban jaane ke baad is page par Dobara check karein dabayein — saare hare ho jaane chahiye.

Pehle admin login zaroori hai

Ye page aapka password nahi maangta. Isi browser me admin panel me login kar lijiye, phir yahan wapas aayiye — login apne aap pakad liya jayega.

Zaroori index

Index se hota kya hai? Bina index ke code poora data (500 tak) laakar browser me sort karta hai — jawab sahi aata hai, par slow aur zyada data kharch hota hai. Aur jis din kisi ek list me 500 se zyada rows ho gayin, jawab chupchaap adhoora aane lagega. Index lag jaane par Firestore khud sort karke sirf utne hi rows bhejta hai jitne chahiye.
